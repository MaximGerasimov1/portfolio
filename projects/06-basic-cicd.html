Project 06: Basic CI/CD Pipeline

Project Overview

Цель проекта — автоматизация процессов разработки с использованием GitLab CI/CD. Был настроен автоматический пайплайн, который при каждом пуше в репозиторий собирает проект, проверяет стиль кода, прогоняет тесты, копирует готовый билд на продакшн-сервер и присылает отчет о результате в Telegram.

Key Accomplishments

  • GitLab Runner Setup: Установка и регистрация собственного раннера на Ubuntu Server 22.04 LTS для выполнения задач пайплайна.
  • Multi-stage Pipeline: Написание .gitlab-ci.yml с этапами Build, Style Test, Integration Test и Deploy.
  • Artifacts Management: Настройка сохранения исполняемых файлов после сборки со сроком хранения 30 дней.
  • Automated Deployment: Реализация Bash-скрипта для автоматического деплоя через scp и ssh на удаленную машину.
  • Telegram Notifications: Интеграция с Telegram Bot API для мгновенного оповещения об успехе или провале пайплайна.

CI/CD Configuration & Scripting

Примеры конфигурации пайплайна и скрипта уведомлений, которые обеспечивают работу автоматизации.

# .gitlab-ci.yml (Workflow)
stages:
  - build
  - test
  - deploy
  - notify

build_job:
  stage: build
  script:
    - make s21_matrix
  artifacts:
    paths:
      - build/s21_matrix
    expire_in: 30 days
# notify.sh (Telegram Bot)
#!/bin/bash
STR="Project: $CI_PROJECT_NAME\nStatus: $1"
URL="https://api.telegram.org/bot$TOKEN/sendMessage"

curl -s -X POST $URL -d chat_id=$ID -d text="$STR"
# style_test (Clang-format)
style_check:
  stage: test
  script:
    - clang-format -n *.c
    - if [ $? -ne 0 ]; then exit 1; fi
  allow_failure: false
# deploy.sh (Remote Transfer)
#!/bin/bash
# Копирование на вторую ВМ
scp ./build/s21_matrix user@10.20.0.3:/usr/local/bin/
ssh user@10.20.0.3 "ls -la /usr/local/bin/"
