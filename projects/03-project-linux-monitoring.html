Project 03: Linux Monitoring v1.0

Project Overview

Проект посвящен созданию комплексных инструментов мониторинга на Bash. Основная цель — автоматизировать сбор данных о системе (состояние RAM, сетевые интерфейсы, дисковое пространство) и разработать удобный интерфейс вывода с поддержкой цветовых схем и конфигурационных файлов.

Key Accomplishments

  • System Metrics Gathering: Написан модуль для извлечения данных об ОС, времени работы, сетевых параметрах и памяти с использованием awk, sed и df/free.
  • Visual Customization: Реализована гибкая система настройки цветов терминала (фон и текст) через аргументы командной строки и config.txt.
  • File System Analysis: Разработан скрипт для глубокого сканирования директорий, определяющий типы файлов, их размер и вычисляющий MD5-хэши для исполняемых файлов.
  • Performance Tracking: Внедрен механизм замера времени выполнения скриптов (Execution Time) с использованием наносекундной точности.
  • Robust Scripting: Реализована обработка ошибок, проверка прав доступа к директориям и валидация входных параметров.

Configuration Examples

Ниже представлены ключевые фрагменты логики: сбор данных, управление цветами, анализ файлов и пример конфигурационного файла.

# info.sh (Сбор данных через awk)
export IP=$(hostname -I | awk '{print $1}')
export MASK=$(netstat -rn | awk 'NR==4 {print $3}')
export RAM_TOTAL=$(free -m | awk '/Mem:/ {printf "%.3f GB", $2/1024}')
export RAM_USED=$(free -m | awk '/Mem:/ {printf "%.3f GB", $3/1024}')
# printLogs3.sh (Цветовая палитра)
WHITE='\033[37m'; RED='\033[31m'; GREEN='\033[32m'
WHITE_BG='\033[47m'; RED_BG='\033[41m'

case ${arr[i]} in
    1) new_array[$i]=$WHITE_BG ;;
    2) new_array[$i]=$RED_BG ;;
esac
# main5.sh (Рекурсивный анализ файлов)
# Поиск TOP-10 тяжелых файлов и определение их типа
find "$1" -type f -exec du -h {} + 2>/dev/null | sort -rh | head -n 10 | while read -r size file; do
    file_type=$(file -b "$file" | cut -d, -f1)
    printf "%d - %s, %s, %s\n" $NR "$file" "$size" "$file_type"
done
# config.txt (Настройки интерфейса)
column1_background=2
column1_font_color=4
column2_background=5
column2_font_color=1
# 1-white, 2-red, 3-green, 4-blue, 5-purple, 6-black
