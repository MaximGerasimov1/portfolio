Project 01: Linux Infrastructure

Project Overview

Этот проект посвящен базовым принципам работы с UNIX-подобными системами. В ходе работы была развернута и полностью настроена операционная система Ubuntu Server 20.04 LTS.

Key Accomplishments

  • Network Setup: Конфигурация статических адресов через Netplan, настройка проброса портов и работа с DHCP.
  • User Management: Создание пользователей, настройка групп и прав доступа через sudoers.
  • System Security: Настройка SSH-демона (авторизация по ключам, смена стандартного порта).
  • Disk & LVM: Работа с разделами диска, мониторинг свободного места (df, du, fdisk).
  • Automation: Настройка планировщика CRON для выполнения фоновых задач (например, логирование uptime).

Configuration Examples

Ключевые фрагменты конфигурации сети и SSH, демонстрирующие навыки работы с YAML-структурами и системными конфигами.

# /etc/netplan/00-config.yaml
network:
    ethernets:
        enp0s3:
        dhcp4: no
        addresses: [10.10.10.10/24]
        gateway4: 10.10.10.1
        nameservers:
            addresses: [8.8.8.8]
    version: 2
# /etc/ssh/sshd_config
Port 2222
PermitRootLogin no
PubkeyAuthentication yes
PasswordAuthentication no
AllowUsers max slavchik
