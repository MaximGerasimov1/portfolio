Project 02: Linux Network Administration

Project Overview

Этот проект посвящен углубленному изучению сетевых технологий в Linux. В ходе работы была построена сложная виртуальная инфраструктура с маршрутизаторами, частными подсетями, DHCP-серверами и настроенным сетевым экраном для управления трафиком.

Key Accomplishments

  • Network Planning: Глубокая работа с ipcalc, расчет масок, адресов сетей и широковещательных адресов.
  • Routing Setup: Настройка статической маршрутизации между несколькими узлами и роутерами через Netplan.
  • Diagnostic Tools: Использование ping, traceroute, telnet и iperf3 для анализа доступности и скорости каналов.
  • Firewall (iptables): Настройка правил фильтрации трафика, работа с цепочками и реализация MASQUERADE (NAT).
  • Network Services: Установка и полная конфигурация DHCP-сервера для автоматической выдачи IP внутри подсетей.
  • SSH Tunneling: Реализация Local и Remote TCP Forwarding для доступа к внутренним веб-сервисам Apache.

Configuration Examples

Примеры настройки сетевых интерфейсов, правил фаервола и динамической адресации, обеспечивающих связь между сегментами сети.

# /etc/netplan/00-installer-config.yaml
network:
  version: 2
  ethernets:
    enp0s8:
      addresses: [10.10.0.1/18]
      nameservers:
        addresses: [8.8.8.8]
# Firewall NAT Rules (r2)
iptables -F
iptables -F -t nat
iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
iptables -A FORWARD -p icmp -j ACCEPT
# /etc/dhcp/dhcpd.conf
subnet 192.168.100.0 netmask 255.255.255.192 {
    range 192.168.100.2 192.168.100.10;
    option routers 192.168.100.1;
    option domain-name-servers 8.8.8.8;
}
