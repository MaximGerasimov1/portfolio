Project 08: Infrastructure Automation & Service Discovery

Project Overview

Проект сфокусированный на концепции Infrastructure as Code (IaC). Основная задача заключалась в полной автоматизации процесса развертывания и настройки парка виртуальных машин с помощью Ansible, а также в реализации динамического обнаружения сервисов (Service Discovery) и управления трафиком через Consul.

Key Accomplishments

  • Ansible Roles Development: Создана модульная структура ролей для установки Consul (Server/Client), базы данных PostgreSQL и Java-микросервиса. Это обеспечило повторяемость и чистоту кода автоматизации.
  • Service Discovery & Mesh: Настроен Consul Connect для обеспечения безопасной сетевой связности между API и DB через Sidecar-прокси, исключая необходимость использования жестко прописанных IP-адресов.
  • Automated Provisioning: Развернут кластер из 3-х нод (Manager, API, DB) через Vagrant. Весь процесс настройки ПО и сетевых политик инкапсулирован в Ansible Playbooks.
  • Deep Troubleshooting: Проведен дебаг микросервиса, в ходе которого была выявлена и исправлена ошибка типизации данных (Long vs Integer) в Spring-контроллере при интеграции с PostgreSQL.
  • Remote Configuration: Реализовано динамическое управление конфигурациями с использованием шаблонизатора Jinja2 для генерации файлов consul.hcl на лету.

Automation Workflow

Ниже представлены фрагменты основного плейбука и конфигурации Consul Connect, которые связывают сервисы в единую отказоустойчивую экосистему.

# site.yml (Main Playbook)
- hosts: consul_server
  roles:
    - install_consul_server

- hosts: api, db
  roles:
    - install_consul_client

- hosts: db
  roles:
    - install_db
# consul_client.hcl (Connect)
connect {
  sidecar_service {
    proxy {
      upstreams {
        destination_name = "db"
        local_bind_port = 5432
      }
    }
  }
}
# Ansible Task (Service Install)
- name: Start the hotels-service
  systemd:
    name: hotels
    state: started
    enabled: yes
    daemon_reload: yes
# Verification (Consul UI)
# Проверка регистрации сервисов
consul catalog services
# Доступ через проброшенный порт
http://localhost:8500/ui
