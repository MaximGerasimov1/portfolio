automation

Bash-инструментарий сбора состояния системы

Первый шаг к автоматизации: ручные команды диагностики заменяются модульными скриптами.

Задача

Собрать срез состояния сервера — hostname, временная зона, версия ОС, uptime, IP, RAM, диск — одной командой вместо десятка ручных вызовов, с настраиваемым форматом вывода и защитой от некорректного ввода.

Что сделано

  • Сбор данных. Скрипт, который собирает системную информацию и выводит её в едином формате — так, чтобы результат можно было сравнивать между запусками и между машинами.
  • Модульная структура. Логика разделена по файлам (main.sh, info.sh, printLogs.sh): сбор данных, обработка и вывод не перемешаны в одном скрипте.
  • Внешняя конфигурация. Цветовые схемы вывода задаются не в коде, а в отдельном config.txt; скрипт читает файл и применяет параметры.
  • Валидация ввода. Проверка количества и корректности аргументов, проверка допустимости значений из конфигурационного файла, понятные сообщения об ошибках вместо падения с непонятным выводом.
  • Логирование. Запись результатов работы в файл для последующего разбора.

Результат

  • Состояние сервера собирается одной командой и в одинаковом формате — результаты сопоставимы между машинами.
  • Формат вывода меняется правкой конфигурационного файла, без правки кода и без риска сломать логику сбора.
  • Скрипт не падает на некорректном вводе, а сообщает, что именно не так.

Стек

  • grep / awk / sed / cut
  • /proc
  • конфигурационные файлы
