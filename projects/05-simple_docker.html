Project 05: Simple Docker

Project Overview

Проект посвящен изучению основ контейнеризации с использованием Docker. В ходе работы был пройден путь от использования готовых образов до создания собственной многоконтейнерной архитектуры с веб-сервером на C (FastCGI), проксированием через Nginx и обеспечением безопасности образов.

Key Accomplishments

  • Custom Web Server: Написан мини веб-сервер на языке C с использованием библиотеки fcgi, отдающий приветственную страницу.
  • Dockerfile Optimization: Создан Dockerfile для сборки образа с Nginx и FastCGI сервером. Настроена работа от не-root пользователя для повышения безопасности.
  • Security Auditing: Проведена проверка образа утилитой Dockle, устранены уязвимости и ошибки конфигурации (удаление кэша пакетного менеджера, настройка прав доступа).
  • Infrastructure as Code: Реализовано развертывание через docker-compose, объединяющее прокси-сервер и приложение в общую сеть.
  • Nginx Proxy Configuration: Настроено проксирование запросов с внешнего порта 8080 на внутренние порты контейнеров для реализации схемы разделения нагрузки.

Implementation Details

Ниже представлены фрагменты кода сервера, конфигурации Nginx и Docker-оркестрации.

# server.c (FastCGI Server)
#include "fcgi_stdio.h"
#include <stdio.h>

int main(void) {
    while (FCGI_Accept() >= 0) {
        printf("Content-type: text/html\r\n\r\n");
        printf("<html><body>Hello World!</body></html>");
    }
    return 0;
}
# Dockerfile (Part 5: Secure Image)
FROM nginx:latest
USER root
RUN apt-get update && apt-get install -y gcc ...
USER nginx
HEALTHCHECK --interval=5m --timeout=3s \
  CMD curl -f http://localhost/ || exit 1
# nginx.conf (Proxy Logic)
server {
    listen 81;
    location / {
        fastcgi_pass 127.0.0.1:8080;
        include fastcgi_params;
    }
    location /status {
        stub_status on;
    }
}
# docker-compose.yml
services:
  server:
    build: .
  nginx_proxy:
    image: nginx:latest
    ports:
      - "80:8080"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
