# 🌐 Personal Engineering Portfolio

Это исходный код моего персонального веб-портфолио. Сайт спроектирован как витрина моих навыков в области **DevOps**, **Backend** и **System Administration**, объединяя описание кейсов с прямыми ссылками на реализацию.

---

## 🎨 Design & Features
* **Modern UI:** Чистый, минималистичный дизайн с акцентом на контент.
* **Case Studies:** Детальные страницы для каждого DevOps-проекта с примерами конфигураций.
* **Responsive:** Полная адаптивность под мобильные устройства и планшеты.
* **Fast Performance:** Чистый HTML/CSS без тяжелых фреймворков для мгновенной загрузки.

## 🚀 Deployment
Сайт статичен и может быть развернут на любой платформе:
  1. GitHub Pages: Автоматический деплой из ветки master.
  2. Nginx: Простое копирование файлов в /var/www/html/.

```
# Локальный запуск
git clone [https://github.com/MaximGerasimov1/maxim-portfolio.git](https://github.com/MaximGerasimov1/maxim-portfolio.git)
cd maxim-portfolio
# Откройте index.html в браузере
```
