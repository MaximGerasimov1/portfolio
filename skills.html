Технический стек

Оркестрация
и контейнеры

  • Docker, Dockerfile, Docker Compose — собственные образы, многоконтейнерные сборки, запуск не от root, проверка образов Dockle (контейнеризация).
  • Docker Swarm — кластер из трёх узлов, стеки, оверлейные сети, глобальные и реплицированные сервисы (Docker Swarm, наблюдаемость).
  • Kubernetes — собственные манифесты, ConfigMap и Secret, деплойменты, сервисы, стратегии обновления, PV/PVC, Ingress (манифесты, кластер k3s).
  • k3s — сборка кластера из трёх узлов вручную, ingress-nginx вместо Traefik, cert-manager (кластер k3s).
  • Helm, Kustomize — чарт с генерацией сервисов по values, база и оверлей, генераторы ConfigMap и Secret (Kustomize и Helm, CI/CD в Kubernetes).

CI/CD

  • GitLab CI — многостадийные пайплайны, правила запуска по веткам и тегам, ручное подтверждение, артефакты и JUnit-отчёты (первый пайплайн, CI/CD в Kubernetes).
  • GitLab Runner — на отдельной машине и как под в Kubernetes-кластере с executor kubernetes, RBAC и лимитами ресурсов (CI/CD в Kubernetes).
  • Newman / Postman — функциональные тесты как стадия пайплайна (CI/CD в Kubernetes).
  • Git — ветвление по фиче, теги релизов, работа с .gitignore и очистка индекса от попавших туда файлов.

IaC
и конфигурация

  • Ansible — роли, плейбуки, инвентарь, шаблоны Jinja2 для конфигов и systemd-юнитов, handlers (Ansible и Consul).
  • Vagrant — воспроизводимые стенды из 3–5 виртуальных машин с provision-скриптами.
  • HashiCorp Consul, Envoy — service discovery, health checks, sidecar-прокси (Ansible и Consul).

Наблюдаемость

  • Prometheus — scrape-конфигурации, обнаружение целей через DNS, правила алертинга, PromQL (логи и метрики, наблюдаемость).
  • Grafana — дашборды на PromQL и LogQL, provisioning источников данных.
  • Loki и Promtail — централизованный сбор логов контейнеров со всех узлов кластера.
  • Alertmanager — маршрутизация уведомлений, собственные шаблоны сообщений, отправка в Telegram и на почту.
  • Экспортёры — node_exporter, cAdvisor, blackbox_exporter, а также собственный экспортёр на Bash.
  • Spring Boot Actuator, Micrometer — прикладные счётчики в коде сервисов.

ОС и сети

  • Linux (Ubuntu, Debian) — администрирование, systemd, права доступа, cron, работа с журналами.
  • Сети — подсети и маски, статическая и динамическая маршрутизация, DHCP, DNS, NAT, iptables, SSH-туннели, диагностика через traceroute, tcpdump и iperf3 (сетевой стенд).
  • Nginx — обратное проксирование, ограничение доступа к внутренним API, разбор access-логов.
  • Виртуализация — libvirt / Vagrant, стенды из нескольких машин.

Языки
и данные

  • Bash — основной инструмент автоматизации: модульные скрипты, валидация ввода, провижининг, замеры.
  • Python — учебные задачи по обработке данных и автоматизации.
  • SQL, PostgreSQL — выборки, соединения, агрегация; инициализация схемы БД при развёртывании.
